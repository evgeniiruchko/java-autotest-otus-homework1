# UI-тесты для wishlist.otus.kartushin.su

Учебный проект по Selenium WebDriver.

## Что проверяется

* `WishlistTest` — вход, переход в «Мои списки», открытие списка «Мой список»
  и поиск самого дорогого и самого дешёвого подарка через Stream API.
* `UsersTest` — вход, переход в «Пользователи», ожидание загрузки списка;
  поиск вторго пользователя, подсветка карточки, снятие подсветки
  и переход в его списки желаний через `Actions`.

## Требования

* JDK 17 или новее.
* Chrome и Edge. Подходящий драйвер WebDriverManager скачает сам,
  устанавливать его вручную не нужно.

### Параметры для запуска

| Параметр | Обязательный | По умолчанию | Описание |
|----------|--------------|--------------|----------|
| `login` | да | — | Логин пользователя |
| `password` | да | — | Пароль |
| `browser.name` | нет | `chrome` | `chrome` или `edge` |
